# AGT Platform UI kit
Farmer-facing web app: sign in → overview → field monitoring → field report → loan.
Screens: `Login.jsx`, `Dashboard.jsx`, `FieldScreen.jsx`, `Report.jsx`, `Loan.jsx`; chrome + charts in `Shell.jsx`; mock data in `data.js`.
All primitives come from the compiled bundle (`window.AGTDesignSystem_48f3d6`). No original product source was supplied — this kit is an original proposal built on the AGT foundations, not a recreation. Satellite imagery is a placeholder (NDVI view is a token-coloured grid).
